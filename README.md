# Турецкий с нуля

Курс турецкого языка от алфавита до B1. Работает на телефоне и компьютере, ставится иконкой, после первого открытия работает без интернета.

- Сайт: https://sergo-proggger.github.io/turkish/
- Репозиторий: https://github.com/sergo-proggger/turkish (файлы из `dist/` лежат в корне ветки `main`, Pages из `main` / root)

## Что внутри

- 32 урока: A1 (14), A2 (12), B1 (6). В каждом подробная теория с таблицами, слова с озвучкой, диалог, фото-обложка.
- Практика в стиле Duolingo: выбор ответа, ввод с турецкой клавиатурой, сборка фразы из слов, задания на слух, «Что на картинке?». Ошибки возвращаются в конец занятия.
- Ударный режим: дневная цель в XP, дни подряд, неделя на главной, календарь в профиле, заморозки серии (одна за каждые 7 дней, максимум 2).
- Интервальное повторение слов (1, 3, 7, 14, 30 дней) и работа над ошибками.
- Виджет для iPhone через приложение Scriptable (`widget-scriptable.js`).

## Файлы

| Файл | Что внутри |
|---|---|
| `course-1.js` … `course-4.js` | уроки: теория, слова, диалоги, упражнения (формат описан в начале `course-1.js`) |
| `photos.js` | фото уроков с Wikimedia Commons (автор и лицензия) и картинки-эмодзи к словам |
| `app.js` | экраны, упражнения, ударный режим, повторение, профиль |
| `style.css`, `index.html`, `manifest.webmanifest`, иконки | оформление и установка |
| `widget-scriptable.js` | виджет для Scriptable на iPhone |
| `icon.swift` | рисует иконки: `swiftc -O icon.swift -o icon && ./icon 512 icon-512.png any` |
| `test-course.js` | самопроверка данных курса |
| `build.js` | самопроверка + сборка `dist/` и `sw.js` с новой версией кэша |

## Как обновить

1. Поправить уроки, запустить `node build.js` (должно быть «Всё в порядке»).
2. Загрузить все файлы из `dist/` в репозиторий: github.com → Add file → Upload files. Пути с кириллицей загрузчик не принимает, поэтому сначала скопировать `dist/` во временную папку.
3. Телефон подхватит обновление при следующем открытии с интернетом.

Прогресс хранится в браузере на каждом устройстве отдельно. В профиле есть «Сохранить в файл» и «Загрузить из файла» для переноса.
